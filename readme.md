# 《黄山奇石》助读素材

人教版语文二年级上册 第四单元 第9课《黄山奇石》配套音画助读素材。

## 内容简介

通过「分段文字朗读 + 对应的 AI 实景插图」，帮助二年级学生直观理解课文内容，感知黄山怪石的奇特有趣，辅助朗读与背诵。

## 文件说明

| 文件 | 说明 |
| ---- | ---- |
| `黄山风景区` | 课文全文本（含 AI 绘图提示词与字幕原文） |
| `N 字.mp3` | 分段朗读音频（序号对应课文句序） |
| `N 字.png` | 对应句子的实景风格插图（AI 生成） |

## 使用说明

1. 按序号依次播放 `*.mp3` 朗读音频，同步观看对应 `*.png` 插图；
2. 可先听音频跟读，再结合插图复述课文，理解怪石的样子与名字的由来；
3. 结尾处可让学生给「叫不出名字的怪石」起名字，进行想象与表达训练。
